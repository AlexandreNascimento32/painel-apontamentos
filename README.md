# Painel de Apontamentos

Painel dos apontamentos de produção de novembro/2026, por máquina e por dia: horas de produção, acerto e parada, quantidade produzida, erros de apontamento marcados pela Qualidade e ranking de operadores com mais falhas.

Acesse: https://alexandrenascimento32.github.io/painel-apontamentos/

Os dados vêm da planilha `Apontamentos_Novembro_2026.xlsm` e ficam dentro do próprio `index.html`.
